# WeChat iLink Bot

基于对接OpenClaw的微信 iLink 协议的微信ClawBot机器人，支持扫码登录，实现接收任意消息和自动推送。
此方法需要先使用手机端发送一条任意消息，以绑定用户 ID。后续运行时，机器人会自动保存登录凭证，避免重复扫码。
微信云端限制发送超过10条信息时，就需要手机端发送一条任意消息，以刷新登录凭证。

## 功能

- 微信扫码登录获取 Bot Token
- 自动保存登录凭证，避免重复扫码
- 接收用户消息并提取用户 ID
- 向指定用户推送消息

## 环境要求

- Python 3.7+
- requests 库

## 快速开始

### 1. 安装依赖

```bash
pip install requests
```

### 2. 运行脚本

```bash
python push_wechat.py
```

首次运行会显示二维码，需用微信扫码确认登录。登录成功后凭证会自动保存到 `credentials.json`，后续运行将自动跳过扫码。

## 文件说明

| 文件 | 说明 |
|------|------|
| `push_wechat.py` | 主脚本，处理登录、消息接收和推送 |
| `credentials.json` | 自动生成的凭证文件（Token、Bot ID、User ID） |

## 注意事项

- `credentials.json` 包含敏感信息，请勿提交到公开仓库
- 二维码过期后需重新运行脚本
- 首次运行需要向机器人发送一条任意消息以绑定用户 ID
